# My Portfolio Website

Welcome to the repository for my personal portfolio website! This project showcases my skills and projects, providing an interactive and visually appealing experience.

---

## ✨ Features

* **Responsive Design:** Optimized for various devices, from desktops to mobile phones.
* **Interactive 3D Elements:** Engaging 3D models and animations powered by **Three.js**.
* **Smooth Animations:** Fluid and dynamic user interfaces thanks to **GSAP**.
* **Modern UI:** Clean and responsive styling with **Tailwind CSS**.
* **Project Showcase:** Dedicated section to highlight key projects.
* **Resume Section:** Easily view and download my resume.
* **Contact Form:** A convenient way to get in touch.

---

## 🛠️ Technologies Used

This website is built with a powerful and modern stack:

* **React.js**: A JavaScript library for building user interfaces.
* **Three.js**: A JavaScript 3D library that makes it easier to display animated 3D computer graphics on the web.
* **GSAP (GreenSock Animation Platform)**: A robust JavaScript animation library for creating high-performance animations.
* **Tailwind CSS**: A utility-first CSS framework for rapidly building custom designs.
* **Vite**: A fast build tool that provides an extremely quick development experience.
